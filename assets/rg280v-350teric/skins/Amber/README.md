# Amber

An original plumOS 350teric skin based on the approved black/orange design mockup.
All labels, selection markers, clock and battery readings are drawn dynamically.
The frame and small device line drawings are common reusable assets, generated
by `scripts/build-rg280v-350teric-amber-assets.py`; no third-party skin artwork or
game screenshots are embedded. The common 350teric font supplies Japanese glyphs.

This skin requires the plumOS `instrumentStyle` renderer extension. At 320x240 it
uses six list rows, muted gray unselected symbols and orange selected symbols.
L/R changes native categories, START opens settings and SELECT edits links.
In the ROM selector A launches, B goes up a directory, X adds a favorite and START
returns to the launcher. Emulator menus retain SELECT+START.
