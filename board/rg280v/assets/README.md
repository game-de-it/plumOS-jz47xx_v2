# RG280V boot artwork

`bootlogo.bmp` is the shared plumOS boot artwork used by the V90S, A30,
MF, and Bubble ports. This copy comes from
`plumOS-Bubble/package/boot-assets-common/plumos-640x480.bmp`,
whose asset record identifies the original as
`plumOS-V90S_v2-public/package/boot-assets-v90s/bootlogo.bmp`.

SHA-256: `6b4be39f18289bffe0a9ea65c11f0d479fd12946bd67154ae7332350df795fa8`

The build converts the unmodified artwork to the RG280V framebuffer's
320×480 memory layout. The panel shows that layout as 320×240.
