# v0.1.0 source bundles

The v0.1.0 release attaches two project-wide source archives and component-specific archives. The platform archive contains the pinned Linux and Buildroot sources, the kernel configuration and overlays, UBIBoot and the system package sources and notices. The runtime archive contains emulator, core and app source snapshots, build recipes, provenance and the component license texts. Both were prepared from the validated base of the release. The [final image changes](../validation/jz47xx-v0.1.0-update-validation.md#未使用のopkとlibretroコアを整理した候補) removed unused programs and retained the active executable bytes.

The FBA44 relink materials are included alongside its modified sources. Component-specific archives cover Genesis Plus GX for OpenDingux, CrocoDS, FCEUX 2.2.3, PocketSNES, and RACE. See `SOURCE-SHA256SUMS` for the source asset hashes and `SHA256SUMS` for the SD image and 7z archive. Third-party licensing terms appear in [Third-party notices](../../THIRD_PARTY_NOTICES.md) and in the source packages.
