# 既存SAとRG350 OPK候補の重複確認（2026-11-17）

既存SAの起動ラッパーが選ぶOPK 5本は、Mac側と端末側のパッケージSHA-256が一致した。そのパッケージと配布62 OPKを展開し、エミュ本体ELFのSHA-256を比較した。OPK全体が異なっても、本体ELFが一致すれば別エミュ候補から外す。設定差は既存SAの比較として扱う。版名が同じでも本体が異なる場合は別ビルドとして残す。

| OPK候補 | 既存SAとの差 | 判断 |
| --- | --- | --- |
| FCEUX 2019（#11） | ELF内の版表示は2.2.3-interim git。既存SAは2.6.6-interim git。本体ハッシュも異なる | 旧版の比較として残す。Apps表示名に2.2.3を付ける |
| PocketSNES（#20） | パッケージ名に加え、本体ELFが既存SAと完全一致 | 重複として別候補から除外。既存SAを使う |
| Gambatte 2021（#36） | `gambatte-dms.gcw0`が既存SAと完全一致。SA側は`--resampler 0`とメニュー補助ライブラリを付けて起動 | 別候補から除外し、Appsの3項目も削除。音声差は既存SAの設定比較として扱う |
| Gambatte 2020（#35） | r572u4表記は同じだが、OpenDingux本体のハッシュが異なる | 2020ビルドとして残す |
| Gambatte 2019 GB/GBC（#37/#38） | r572u3で、既存SAのr572u4とは版も本体も異なる。#37と#38同士は本体が一致 | 同じr572u3エミュとしてまとめ、GB/GBCそれぞれのROM試験入口は残す |
| ReGBA 2019（#26） | 配布原版の本体と既存RG280V版の本体は異なる | 別ビルドとして残す。版名だけで同一とはしない |
| PicoDrive（#19/#52/#53/#54） | いずれも既存RG280Vビルドと本体が異なる。#52/#53/#54同士は本体一致 | 別ビルド候補として残すが、32X/CD/MDは同じエミュの機種別入口として数える |
| PCSX4ALL（#51） | 配布原版の本体と実機の既存SA本体はハッシュが異なる | 別ビルド扱い。既存SAの動作実績を配布版へ移さない |

## 完全一致した本体のSHA-256

| 既存SA | 一致した候補 | 本体SHA-256 |
| --- | --- | --- |
| pocketsnes | #20 | `e84507e7f779d1030cddac5e950dceff7e8065f4d63efbe1e89f8ce4e55c7312` |
| gambatte | #36 | `70f6d6700c404fba04a7a5c17c24d98cf744cb206c29d763e59af2b56105d280` |

目視比較メニューは10 OPK×3タイトルから、重複Gambatte 2021の3項目を除いた**9パッケージ×3タイトル＝27項目**へ更新した。#37/#38は同じエミュのGB/GBC試験入口なので、独立したエミュ実装数としては8候補。既存のAtari800・Temper・FBAの試験項目は別枠。ROM候補と配布62 OPKの監査履歴は保持する。

再現用スクリプト: `scripts/audit-rg350-sa-duplicates.py`（ビルドコンテナ内で実行）。生成JSONと展開データはGit管理外。
