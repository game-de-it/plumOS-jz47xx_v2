# RG280V TOP機種名と電源操作メッセージの表示修正（2026-11-18）

## 修正

TOPタイルの名前は左右12pxの余白で切り詰めていた。小画面では同じ文字サイズ・従来の左揃えを保ち、右側の余白を6pxに調整。長い名前は空白位置を優先して最大2行に折り返す。空白のない名前もUTF-8コードポイントの境界で折り返す。機種名・アイコン・タイル配置は変更しない。

再起動・シャットダウンの共通進捗画面は、大画面用の座標を320×240の論理画面にも使用していた。見出しがy=8になり、高さ34pxのヘッダーと重なっていた。小画面用に見出し・待機・説明の位置と文字サイズを設定し、ヘッダーから離した。TOP再スキャン画面も同じ共通処理を使う。

## 検証

- MIPS soft-float向けにFEをビルドし、実機への転送SHA-256を照合。FE本体だけ更新し、エミュ・カーネル・電源スクリプトは変更しない。
- 同じ描画関数を使うホスト診断で、有効な全26機種の名前を描画して確認。
- 実機TOPのAmstrad CPCは1行、Master Systemは2行で全体が見えることを画面取得で確認。
- 再起動・シャットダウン画面は、診断専用ルートに8秒待機だけの代替スクリプトを置き、`--dry-run` を指定して実際のFEの電源操作画面を取得。両方ともヘッダーとの重なり、文字切れがない。実際の再起動・電源断はこの検証では行っていない。本番の電源スクリプトは変更していない。
- 画像・ビルドログはGit管理外 `output/rg280v-fe/top-label-fix/` と `output/rg280v-fe/top-label-build.log` に保存。
