# RG280V FEの機種アイコン補完（2026-11-16）

FEの機種タイルはテーマ設定の`system_logo_root`を使い、`logos/systems/<機種ID>.png`を読む。ROMを配置してFEに表示された32X、Sega CD、SuperGrafx、PC Engine CDには、画像がまだなかった。テーマ設定の`system_icon_root`は現行の機種タイル描画では参照されない。

既存15枚がplumOS-A30の既定テーマとSHA-256で一致することを確認し、同じセットから不足する4枚を`assets/frontend/logos/systems`へ追加した。画像名はFEの機種IDと一致する。既存のイメージ生成スクリプトとFE配置スクリプトはこのディレクトリのPNGを一括コピーするため、再生成・再配置にも反映される。

RG280Vへ4枚を配置し、各ファイルをSHA-256で照合した。FE再起動後、全17機種と「お気に入り」「最近使った項目」の計19枚が端末上でローカルの画像と一致した。DRM画面取得でFEの稼働と既存の機種タイル表示を確認した。追加4機種のタイルを実機で目視する試験は未実施。
