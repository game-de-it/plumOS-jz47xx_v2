## Reproducible installation

Run `python3 scripts/install-rg280v-350teric-skins.py` after installing 350teric.
It fetches the pinned sources, prepares copies in ignored
`output/rg280v-350teric/skin-install`, verifies free SD1 space and the transferred
archive SHA256, then adds missing skin directories to
`/media/data/plumos/home/350teric/.esoteric/skins`.

Existing skin directories and the active `esoteric.conf` are not replaced.
A repeated installation was checked: all four existing directories were retained
and the active configuration SHA256 stayed identical.

The preparation retains upstream imagery and colors, records the original
`skin.conf.upstream`, and maps supported configuration keys to 350teric. The
320×240 list uses six rows, 12-pixel body text and 14-pixel title text. Skins inherit
the existing full CJK font; original supplied fonts remain as `font-upstream.ttf`.
Source README/license notices and pinned provenance metadata accompany the copies.
External skin artwork remains outside the tracked repository.

## Runtime fixes needed for skin switching

Upstream's settings change exits the frontend, relying on the original system
launcher to respawn it. The plumOS Apps wrapper now restarts only 350teric on the
explicit exit code 75; normal exit returns to plumOS. The game invoker also exits
75 to the existing wrapper after its child finishes, avoiding a new nested shell
on every game launch.

The shared dialog title icon still cropped large imported machine images, hiding
the ROM-selector title. It now uses the cached aspect-preserving fitted icon
surface, limited to the title-bar cell, and reserves that cell's width for text.
The launcher list/grid icon fix from `0402bdc` is retained.

`51eef5854d0cd402901f6302ab3bbbb3ad31e0ed392d28be48cbd3e4c0a757af`.
