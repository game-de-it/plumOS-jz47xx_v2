# RG280V 32X ROMのFE登録（2026-11-16）

32XがFEに表示されないとユーザーが報告。端末の`systems.json`では`sega32x`は有効で、PicoArch PicoDriveを候補に登録済みだった。一方、SD2の認識対象`roms/sega32x`にROMがなく、空のシステムを非表示にする既定設定によって32Xが隠れていた。

ユーザーのROMライブラリにある32個の7zアーカイブを確認し、各アーカイブに対応する`.32x` ROMが1本ずつ入っていることを検査した。PicoArchの共通コンテンツ処理は7zを展開しないため、全て`.32x`へ展開してSD2へ配置。先に置いたBC Racersはアーカイブ内データとSHA-256が一致したので重複転送しなかった。新規転送31本、既存一致1本、合計32本・100,139,008バイト。各転送では展開サイズとSD2上のSHA-256を照合した。ROM本体とBIOSはGitに含めない。個別ハッシュの作業用マニフェストはGit管理外の`output/rg280v-emulators/rg280v-32x-manifest-20261116.json`に保存した。

SD2は転送時だけ読み書き可能へ切り替え、`sync`後に読み取り専用へ戻した。FEのライブラリ再スキャン結果は`sega32x` 32件で、作業用マニフェストの32件とファイル名が一致。FEを再起動し、`plumos-controller-ui --render`のPID 5444がADBシェル終了後も稼働することを確認した。物理画面の32X表示とゲームの映像・音・FPS・操作・FE復帰はユーザー確認待ち。
