# RG280V PCSX4ALL移植（2026-11-16）

[RG350 PCSX4ALL](https://github.com/jdgleaver/RG350_pcsx4all)の `ab17108051d2178465da58ce377225575d680e5e` とlibShakeサブモジュール `7f643c813f1ffea659fb85a47b14d8fbda18cce1` を固定した。公開OPKはHard float ABIのため現在のSoft float rootfsで動かない。`scripts/build-rg280v-pcsx4all.sh` で現行クロスツールチェーンとSDL 1.2を使い、MIPS再コンパイラ、GPU Unai、SDL音声、CHD読み込みを有効にしたSoft float版を再現できる。

`scripts/patches/pcsx4all-rg280v.patch` は、振動機能を無効にしたときの戻り値の型不一致を直し、初期メニュー操作をSELECT＋STARTにし、CHDのZlib初期化エラーで埋め込み領域を `free` してしまう経路を直す。開発ビルド設定 `DEV=1` で低位アドレスへの固定マッピングを避ける。生成した実行ファイルはSoft float ABIで、配布用にはstripした。ソースとGPL文書を画像のデータ領域へ同梱する構成を追加した。ROM・BIOSは同梱しない。BIOSが置かれていない場合はPCSX4ALL自体がHLE BIOSへ切り替える。

SD1の `/media/data/plumos/bin/pcsx4all` に配置し、`plumos-standalone-launch pcsx4all ROM` から起動する。HOME、BIOS、メモリーカードはSD1のデータ領域を使う。FEのPSX候補はPCSX4ALLを既定にし、従来のPCSX ReARMed候補も維持した。`.m3u` は先頭の有効なディスクを開く。ディスク切替の操作は未検証。

## 実機結果

追加パッチで電源キーからPCSX4ALLメニューを開く割り当てを外し、設定を初期値に戻してもSELECT＋STARTが維持されるようにした。後続のTobal 2試験でRG280Vの入力既定値をDigitalへ変更した。修正版をSD1に配置し、SHA-256の一致を確認した。
