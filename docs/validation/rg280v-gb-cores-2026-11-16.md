# RG280V GB候補の実機確認（2026-11-16）

FEの登録順は単体Gambatte、PicoArch Gambatte、Gearboy、VBA-M。ユーザーがGBについて「すべて動作OK」と報告した。端末の`picoarch/gb.log`にはPicoArchのGambatte、Gearboy、VBA-MでSD2の`Zelda no Densetsu - Yume o Miru Shima (Japan).gb`を読み込み、各コアを終了した記録がある。FEのrecentには単体Gambatteで`Super Mario Land [V1.1].gb`の起動履歴がある。

これはユーザーの総合的な実機結果であり、今回の報告から個別候補のFPS数値、音質の内訳、セーブ後の再起動確認までは特定できない。GB候補と既定の単体Gambatteは維持する。次はGBCの4候補を登録順に確認する。
