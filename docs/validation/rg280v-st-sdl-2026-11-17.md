# RG280V SDL Terminal移植（2026-11-17）

上流は [jamesofarrell/st-sdl](https://github.com/jamesofarrell/st-sdl) のコミット `c687e1c57296d468bcad6fd1849f24290b2dae98`。変更は `scripts/patches/st-sdl-rg280v.patch` に保存した。`scripts/build-rg280v-st-sdl.sh` でMIPS Soft float版をビルドし、OPKと変更済みソースを作る。`scripts/make-rg280v-image.sh` に組み込んだ。今回、新規SDイメージ全体は生成していない。

RG280Vでは320×240の端末と仮想キーボードを320×480へ縦2倍に描画する。SDLのダブルバッファ指定では画面更新が失敗したため、同じSDL1.2を使うBardと同様のソフトウェア面と `SDL_Flip` に変更した。物理SELECT＋STARTを終了操作に割り当て、電源ボタンは使用しない。

| 項目 | 結果 |
| --- | --- |
| クロスビルド | 成功。`readelf -A` でSoft float ABIを確認 |
| FE登録 | Apps一覧に `SDL Terminal` を表示。`opkinfo` でメタデータ確認 |
| 起動と画面 | FEから起動。DRM取得画像でヘルプ、端末、仮想キーボードを確認 |
| 入力 | Xで仮想キーボードの表示を切替。十字キーで `q` を選び、Aで端末へ入力できた |
| 終了 | SELECT＋STARTでプロセス終了、Apps一覧へ正常復帰 |
| SD1照合 | OPKとソースアーカイブのSHA-256がMac側と一致 |
