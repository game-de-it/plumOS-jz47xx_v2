# 4機種共通の配布候補イメージ（2026-11-20）

## 組み立て

- RG280V、RG300X、RG350、RG350Mの起動ファイルと機種記憶対応UBIBootを使用した。SD1のp3は空の初期状態で、初回起動時にカード末尾まで拡張する。
- FE以下は許可リストに記載した個別成果物から新規に構築した。ホーム、BIOS、セーブ、ログ、FEのインデックスは空で、前回選んだ機種も入っていない。システムの開発用ADBとSSHデーモン、診断コンソールの起動を除き、既定のシステムアカウントをロックした。
- FEに21システム、49起動経路を登録した。試験版にあったAtari 800、CPC、ZX Spectrum、Neo Geo、Neo Geo CDは、BIOSや同梱データの確認が必要なパッケージを避けるため対象外とした。GBAはBIOSイメージを持つ試験版経路に代え、PicoArchのVBA-Mを登録した。試験版の追加フロントエンドは同梱範囲外。

## 配布候補の検査

- 生成後のイメージを読み取り専用でマウントし、FAT、ext4、rootfs、modules、24個のOPKを展開して調べた。既知のBIOS・セーブ内容13種の実データ、ゲームファイルの代表的なシグネチャ、ROM・BIOS・セーブのファイル名、作業機固有パス、認証情報のパターンは見つからなかった。画像のPNGメタデータを除去した。
- 最終イメージ上の312 ELFについて動的依存ライブラリ名を確認し、未収録の名前がないことを確認した。パーティション表、FAT、ext4、ブートローダー、4機種分のカーネルを照合した。
- 候補を複製した29.76 GiBの仮想カードで、初回p3拡張の中断と再開、ファイルシステム検査、機種設定変更後のデータ保持を確認した。実機での再検証はこれから行う。
- 配布用のXZを展開した内容は原本イメージとSHA-256が一致した。原本とXZの両方のSHA-256を記録した。

## ソース公開前の確認

- 監査時点でローカル参照から到達できる256コミットと1,174個のblobを検査した。過去の文書と一部の現行検証スクリプトに、開発機のパスが残っていた。コミットの作成者・コミッター情報には非公開化が必要なメールアドレスがあった。検査した履歴に秘密鍵や既知のアクセストークン形式は見つからなかった。既存の履歴はそのまま公開せず、公開範囲とコミット情報を整理する。
- イメージの一般公開前に、各同梱バイナリの正確な出所、再配布条件、必要な対応ソースを確認し、配布候補で4機種のコールドブートと代表的な機能を再検証する。
