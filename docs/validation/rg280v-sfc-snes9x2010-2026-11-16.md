# RG280V Snes9x 2010の性能と色（2026-11-16）

SFCのFE登録順最後の候補。SD2の`Super Mario World - Super Mario Bros. 4.sfc`をPicoArchから診断起動した。CPUは996 MHz。14秒の試験では最後の画面更新窓が48.01 FPS。26秒の試験では最後の窓が30.18 FPSになった。短時間試験の3.5秒と7秒のDRM取得画像はほぼ黒。長時間試験の約18秒時点ではタイトルが描かれたが、枠と背景がピンク・シアン・緑などに大きく変色した。

ログの映像更新数は26秒試験で60回時20.22 FPS、180回時の直近窓43.13 FPS、360回時49.1 FPS、600回時30.18 FPS。起動初期だけでなく、表示が安定した後も60 FPSを維持していない。音声PCMには非ゼロ信号があったが、聴感評価は行っていない。自動試験の時間切れはwatchdogで終了し、両試験後にFEプロセスの復帰を確認した。

既にChimeraSNESとSnes9x 2005 Plusが実機で約60 FPS・映像・音・操作・終了まで正常確認済み。Snes9x 2010は60 FPSと正しい色の基準を満たさないため、FE候補から外す。コア本体とビルドレシピは調査用に保持する。取得画像・計測JSONはGit管理外の`output/rg280v-emulators/snes9x2010-long-20261116/`と`output/rg280v-emulators/snes9x2010-long-18s.png`に保存。

FE設定のSHA-256は`05a5f3b88375b86751d5d2c38d476d24d4337c861c52e6b9a24750f0934241b7`。端末に配置・読み戻して一致を確認。FEは再起動後に稼働し、SFCの現在選択はSnes9x 2005 Plusのまま。残る候補順はPocketSNES、Snes9x 2005、ChimeraSNES、Snes9x 2005 Plus。
