# RG280V: 350teric / Esoteric integration

Upstream: https://github.com/podulator/esoteric, release 1.0.12,
commit `6e0a1ca1aa523ec5dff042c4a220582edc1767e9`.
Requested guide: https://retrogamecorps.com/2020/09/26/guide-350teric-esoteric-frontend-on-the-rg350/

## Implementation

This builds the original C++/SDL frontend, with its Default and Minimal skins,
settings, native ROM selector, favorites, Explorer and link editor. It is an Apps
entry; the normal boot frontend remains plumOS. No kernel, SD image, ROM or BIOS
changes are involved.

- Build: `scripts/build-rg280v-350teric.sh` (existing bookworm toolchain image and
  `plumos-jz47xx-rg280v-build` volume).
- Install: `scripts/install-rg280v-350teric.py` (ADB port 5041, target 10.1.1.2:5555).
- Patch: `patches/rg280v-350teric.patch`.
- Runtime: `/media/data/plumos/350teric`; dedicated HOME:
  `/media/data/plumos/home/350teric`, settings under `.esoteric`.
- SD2 ROM paths come from current frontend `systems.json`; each concrete profile
  delegates to `plumos-text-ui launch --no-scan --execute --profile …`.
- Current catalog: 26 systems, 58 distinct profiles. Labels include the frontend
  and core, e.g. `NES - SA:FCEUX`, `NES - PICO:FCEUmm`, `NGCD - SA:NEO4ALL`.
  The default profile appears once with its real name; its description identifies
  it as default. There are no ambiguous additional “Default” entries.
- Standard plumOS system artwork is used for system icons. The longest generated
  title measures 169 pixels with the shipped 12-pixel font.
- Eight installed normal OPK apps are linked through `plumos-opk-app-launch`,
  rather than bypassing the existing compatibility wrappers.
- Games/app exit restarts 350teric and restores its selector. Settings →
  Return to plumOS ends the frontend process and returns to the waiting plumOS FE.

Hardware uses a safe generic backend with 320×240 RGB565 rendering and the
existing SDL KMS scaling to the RG280V panel. CPU register access, stock launcher
installation/uninstallation and SD mount actions are disabled. Idle power timers
are disabled; physical power/volume/brightness remain plumOS responsibilities.
Power actions delegate to `plumos-safe-shutdown`. Battery is read from the actual
jz-battery/usb-charger sysfs entries.

The port also fixes dangling argv pointers in upstream Launcher, modern-compiler
SDL timer pointer comparisons, and invalid image-surface handling. The existing
SDL_image closure lacks JPEG support, so an app-local PNG/JPEG/BMP/GIF/XPM build
and libjpeg are supplied. The standard JPEG wallpaper then loads correctly;
other applications' shared libraries are unchanged. Upstream GPL and font/SDL_image
license notices accompany the runtime.

Installation checks SD1 free space and transfer SHA256. Existing settings, skins,
favorites, custom links and other Apps entries survive reinstallation. Generated
route files are refreshed, with the previous sections/apps JSON backed up under
`/media/data/plumos/backup/350teric-*`. The regenerable runtime seed is replaced,
so obsolete generated Default links cannot leak back from an older seed.

## Device checks

Confirmed with injected physical input events and active DRM-plane screenshots:

- Default skin, stock JPEG wallpaper, tab navigation and repeated directional
  movement (52 individual down presses), A selection and START settings.
- SELECT native link editing menu and ROM directory navigation.
- SD2 ROM enumeration with the extension filters from the registered system.
- PicoArch FCEUmm: ROM launch, SELECT+START menu, Exit and return to the same
  350teric ROM selection.
- Standalone FCEUX: Baseball launch, repeated START input, rendered game screen,
  SELECT+START menu, Exit and return to the ROM list.
- Launch through plumOS START → Apps → 350teric; Settings → Return to plumOS
  restores the Apps screen with 350teric selected.
- Compatible OPK Calculator launch, captured rendered UI after its startup,
  SELECT+START exit and return to 350teric.
- Final generated labels use SA/PICO prefixes; all 58 profiles have explicit
  names, with no `title=…Default` entries.

Screenshots and diagnostic logs are in ignored `output/rg280v-350teric/`:
`menu.png`, `settings.png`, `context.png`, `rom-list.png`, `sa-game.png`,
`sa-menu.png`, `sa-return.png`, `fe-apps.png`, `fe-return.png`,
`final-labels.png`, `apps.png`.

These checks verify frontend integration; they do not constitute a new performance
or physical audio audit of all 58 emulator profiles. Those use the previously
validated plumOS launchers. Additional skins and arbitrary user-supplied OPKs are
not certified by this integration.

## Controls

- D-pad: selection; A: confirm; B: back/up as shown by each native dialog.
- L/R: tabs; START: settings, or leave the ROM selector.
- SELECT: link editor; X: favorite in the ROM selector.
- Settings tab → Return to plumOS: close 350teric.
- Emulator menu remains SELECT+START.
