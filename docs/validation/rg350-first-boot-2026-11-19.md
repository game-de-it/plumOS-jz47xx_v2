# RG350の初回実機検証

ユーザーがRG350用の試験イメージを予備SD1へ書き込み、内蔵液晶にplumOS FEが表示されることを確認した。

| 項目 | 確認結果 |
| --- | --- |
| 機種と起動ファイル | DT `Anbernic RG-350`／`ylm,rg350`、`model.txt=rg350`。SD1の`uzImage.bin`とMacの生成物のSHA-256が一致 |
| USBとストレージ | USB Ethernet経由のADBを確認。SD2挿入後の再起動でも接続でき、`/dev/mmcblk1p1`は読み取り専用でマウント |
| 内蔵液晶 | DRM 320×240／60 Hz、XR24。FE TOPとSTARTメニューを取得。IT66121も認識した。HDMI実出力は未試験 |
| 入力 | `gpio-keys`は`event3`。入力注入で十字キー・A/B・STARTとFE操作を確認 |
| 音量・輝度 | 音量キーでPCM 45→39→45%、START＋左右で輝度8→6→8。両方とも試験前の値へ復帰 |
| 音声 | ALSA `gcw0-audio`。48 kHz／16-bitステレオを`aplay`で送出し、内蔵スピーカーから正常に聞こえたことをユーザーが確認 |
| Sleep | POWERメニューからSleepを実行し、電源ボタンの短押しでFEに復帰。ADBでもdeep suspendのentry／exitと、FE PID 2415の継続を確認 |
| Apps | EmulationStationのSTARTメニューとUI SETTINGS、計算機の結果`777`が320×240に収まることをキャプチャで確認。両アプリは終了コード0 |
| FEからゲーム起動と復帰 | GBA一覧からCastlevaniaをReGBAで起動し、SELECT＋START→Exit後に同じFE PIDのGBA一覧を取得 |

## 代表エミュ経路の試験

SD2のROMを通常の起動ディスパッチャーに渡し、DRM画像と描画更新・PCMを短時間採取した。数値は終盤の更新窓で、ROMの場面やメニュー遷移の影響を含む。プレイ中の長時間のFPSやスピーカーでの聴感の測定値ではない。

| 機種 | 経路 | ROM | 更新/秒（終盤2窓） | PCMピーク | 終了 |
| --- | --- | --- | ---: | ---: | --- |
| NES | PicoArch QuickNES | Super Mario Bros. | 60.0 / 60.0 | 13,481 | メニューExit |
| NES | 単体 FCEUX 2.2.3 | Super Mario Bros. | 60.2 / 55.4 | 15,782 | 試験用停止 |
| SFC | PicoArch ChimeraSNES | Super Mario World | 60.3 / 59.4 | 7,336 | メニューExit |
| GB | 単体 Gambatte 2020 | Super Mario Land | 59.8 / 59.5 | 30,720 | 試験用停止 |
| GBA | 単体 ReGBA | Goodboy Galaxy | 35.0 / 58.1 | 18,944 | 試験用停止。CastlevaniaではFE経由のExitを別途確認 |
| Mega Drive | 単体 PicoDrive | Bare Knuckle | 60.0 / 59.9 | 1,049 | 試験用停止 |
| PC Engine | PicoArch PCE Fast | Air Zonk | 60.0 / 60.0 | 9,356 | メニューExit |
| PSX | 単体 PCSX4ALL | RUNABOUT-2 | 60.2 / 48.7 | 0 | 起動演出とメニュー。試験用停止。走行中の映像・音は未確認 |

試験後のFE TOPとSD2の読み取り専用を確認した。Sleep移行時にはRG300Xの試験と同じ`drm_kms_helper_poll_disable`からの`__flush_work`警告が1回出た。今回の復帰・USB再接続・SD2マウントの継続を確認した。生ログとキャプチャは`output/rg350-validation/`に保存。FE登録全58経路の検証は今回の範囲に含めていない。
