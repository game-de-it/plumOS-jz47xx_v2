# RG280V FFPlay 実機確認（2026-11-17）

## 移植内容

- GCW Zero 向け FFmpeg-GCW0 の `release/2.1-gcw0`、コミット `0ffa36e68a70ef9e3a6d3555427c60df98453edc` を固定した。
- Buildroot の MIPS/uClibc Soft float ツールチェーンで FFPlay と共有ライブラリをビルドした。ビルド手順は `scripts/build-rg280v-ffplay.sh` に記録した。
- RG280V の 320×480 フレームバッファが物理的には 320×240 に表示されるため、FFPlay の表示比率を補正した。
- 動画表示で `SDL_HWSURFACE` を使うと `SDL_FillRect` 内で SIGBUS になったため、RG280V では `SDL_SWSURFACE` を指定した。
- SD1/SD2 の動画・音声ファイルを選べる SDL ファイルブラウザーを追加した。OPK と変更済みソースを SD イメージへ同梱する。

## 機械的な確認

- `bash -n` でビルド・イメージ作成スクリプトの構文を確認した。
- `readelf -A` で FFPlay が Soft float ABI であることを確認した。
- OPK とソースアーカイブを RG280V に転送し、転送前後の SHA-256 が一致した。
- 8秒の合成 AVI を単独起動で最後まで再生した。ログ上では 240 フレームのうち 8 フレームがドロップした。取得した DRM 画面に色帯と円が表示された。
- FE の Apps から FFPlay → SD1 → Movies → 30秒の合成 AVI を起動した。再生中の DRM 画面に色帯と円が表示され、再生終了後は FE の Apps 一覧へ戻った。

## 黒画面の切り分け

- 単独起動の直後、FE プロセスが存在しない状態で画面が黒くなり、ユーザーから黒画面の報告を受けた。
- FE を再起動し、DRM 画面取得で表示を確認した。その後の通常の FE → Apps 経路では、30秒動画の再生中と終了後の両方で画面表示を確認した。
- 実機の視認性、音質、操作はユーザーの確認を待つ。画面取得だけで音質は判定しない。
